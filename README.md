# SmartStudy - Indian Board Exam Preparation Platform (Class 11 & 12)

A modern, clean, and trusted Indian educational web platform designed specifically for Class 11th and 12th students preparing for **CBSE (Central Board of Secondary Education)** and **MP Board (Madhya Pradesh Board of Secondary Education)** examinations.

---

## 🌟 Key Features

### 1. Dual Board Adaptation (CBSE & MP Board)
- **Instant Board Switcher** in the header allowing students to toggle between CBSE and MP Board (MPBSE).
- Tailored for the **CBSE 50% Competency-based Question Pattern** and **MP Board Blueprint & Question Bank**.
- High-yield bilingual support for Hindi & English medium students.

### 2. Complete Multi-Page Architecture
- **Homepage:** Complete with all 9 core educational sections:
  1. **Header:** Brand Logo, Board Selector, Search Bar, Navigation Links, Mobile Drawer & Student Login.
  2. **Hero Section:** "Your Board Exam Preparation Starts Here!", Subtitle, Explore Class 11 & Explore Class 12 CTA buttons, and custom Indian educational illustration.
  3. **Class Selection:** Dedicated Class 11 (Foundation) & Class 12 (Board Mission 95%+) sections with subject chips.
  4. **Subject Catalog:** Physics, Chemistry, Mathematics, Biology, English Core, and Computer Science with codes and chapter stats.
  5. **Study Resources:** 6 High-yield categories (NCERT Solutions, Chapter-wise Notes, Important Questions, Previous Year Papers, Sample Papers, Formula Sheets).
  6. **Test Preparation:** Timed Chapter tests, Subject-wise tests, and Full-length Board Mock Tests with duration, questions, and marks.
  7. **Latest Updates:** Real-time CBSE & MPBSE circulars, datesheet notifications, and downloadable PDFs.
  8. **Why Choose SmartStudy:** 4 Core pillars (Easy Learning, 100% Organized, Regular Timed Practice, Exam-focused Prep).
  9. **Footer:** About Us, Contact, Privacy Policy, Terms, and direct links to official Indian portals (CBSE, MPBSE, NCERT, Pariksha Pe Charcha, DIKSHA).
- **Dedicated Class 11 Page:** Chapter-by-chapter breakdowns for all 6 subjects with weightage and instant notes access.
- **Dedicated Class 12 Page:** Board exam focused layout with 5-year PYQs, NCERT solutions, and formula summaries.
- **Interactive Chapter Reader Modal:** Digital notes reader with text zoom controls, print preview, notes copy, and PDF download simulation.
- **Interactive Live Test Engine:** Timed test portal with countdown timer, question palette, review later flag, immediate score report, accuracy percentage, celebration confetti, and step-by-step explanations.
- **Student Auth Portal:** Realistic Indian mobile OTP simulation and email login with student dashboard showing test scores and grade info.
- **Contact & Doubts Help Desk:** Student query submission form, Indore & Delhi center details, and comprehensive FAQs.

## 🎨 Design Theme & Colors

- **Primary Colors:** Royal Blue (`#1e40af` / `#1e3a8a`) and Teal accents (`#0d9488` / `#14b8a6`).
- **Section Backgrounds:** Soft light blues (`#f0f7ff`, `#f8fafc`) and crisp whites.
- **Typography:** 'Plus Jakarta Sans' & 'Inter' for clean, readable Indian academic styling.
- **Cards & Elements:** Simple rounded corners, subtle shadows, academic badge styling, and clean hover states without distracting gradients.

## 🚀 How to Run Locally

### 1. Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Production Build
```bash
npm run build
```
Creates optimized static build inside the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```
